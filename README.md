# 「エフェクトトリガー」プラグイン

> [!WARNING]
> v2.0 は v1.0 と互換がありません。v1.0 で作ったプロジェクトを開くと、エフェクトトリガーは読み込まれません。
> v1.0 から更新するときは、YMM4 の `user\plugin\EffectTrigger` フォルダに `Trigger.dll` が残っていたら消してください。残っていると「エフェクトトリガー」が 2 つ表示されます。

### [最新バージョンをダウンロード](https://github.com/Dolphin-kun/EffectTrigger/releases/latest)

## 概要
指定した条件を満たすときにエフェクトを実行させる映像エフェクトプラグインです。  
エフェクトの入れ子部分に簡易カーニングのコードを参考にさせていただきました。

エフェクトを適用しているアイテムが条件を満たしたときに、中に入れたエフェクトを適用したり、画像を差し替えたりできます。

## 使い方
「描画」から「エフェクトトリガー」を追加してください。

## 効果
### 条件
if の部分です。  
「X が 0px に等しいとき」のように表示されるので、それを見ながら調整してください。

### 対象
条件で調べる値です。

|対象||
|-|-|
|X|描画位置（横方向）|
|Y|描画位置（縦方向）|
|Z|描画位置（奥行き）|
|不透明度|不透明度|
|拡大率X|拡大率（横方向）|
|拡大率Y|拡大率（縦方向）|
|回転角X|縦方向、X軸に対する回転角|
|回転角Y|横方向、Y軸に対する回転角|
|回転角Z|平面方向、Z軸に対する回転角|

### 条件
対象と「値」の比べ方です。

|条件||
|-|-|
|=|値に等しい|
|≠|値と等しくない|
|>|値より大きい|
|<|値より小さい|
|≥|値以上|
|≤|値以下|
|範囲|下限以上、上限以下|

「範囲」を選ぶと、スライダーが「下限」と「上限」の 2 本になります。

「=」は値がぴったり同じときだけ満たします。動いている途中では値がちょうど一致することはほとんどないので、そういうときは「範囲」で幅を持たせてください。

### リセット
条件を満たすたびに、中のエフェクトを最初から適用します。  
登場退場も使用可能です。

### 確率
条件を満たしたときに、実際に適用するかどうかを確率で決めます。100% なら毎回適用します。

### 画像
条件を満たしている間、元の映像の代わりに選んだ画像を表示します。画像は元の大きさのまま、中央に置かれます。  
空にしておくと差し替えません。

### 実行エフェクト
条件を満たしたときに適用するエフェクトです。  
画像を選んでいるときは、差し替えた画像に適用されます。
